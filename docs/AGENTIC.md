# Agentic testing

The repo ships Playwright's test agents for Claude Code (generated by
`npx playwright init-agents --loop=claude`):

| Agent | File | Does |
|---|---|---|
| Planner | `.claude/agents/playwright-test-planner.md` | explores the running app and writes a test plan to `specs/*.md` |
| Generator | `.claude/agents/playwright-test-generator.md` | turns a plan into Playwright tests, checking each step live |
| Healer | `.claude/agents/playwright-test-healer.md` | runs failing tests, finds the cause, repairs the test or marks it as an app bug |

They drive the browser through the Playwright test MCP server in `.mcp.json`, starting from
`tests/seed.spec.ts` (hermetic fixture, app loaded).

## The loop

```
new feature ─► planner ─► specs/<feature>.md ─► human review ─► generator ─► tests/e2e/*.spec.ts
                                                                                  │
nightly red / heal report ─► healer ─► fix test  or  add entry to known-issues.ts ─┘
                                            │
                                     PR ─► pr.yml gate ─► human review ─► merge
```

## Rules

- Agents work on a feature branch and open a PR; they never push to `main`.
- A healer fix to a *test* needs the reason in the PR. A real app defect goes to
  `framework/config/known-issues.ts` with `test.fail`, never a weakened assertion.
- Generated tests use the framework fixtures (`framework/fixtures`) so they stay hermetic.

## Use

```
claude  →  "Use the playwright-test-planner agent to plan tests for the stops drawer"
claude  →  "Use the playwright-test-healer agent on the failing nightly tests"
```
